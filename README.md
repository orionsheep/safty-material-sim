# 卫华安全库存模拟平台

这是 f-1「生产类安全库存」页面的本地副本。物料清单和出入库从真实系统拉下来，试算、改参数、看曲线都在这里做，不改线上数据。

线上快照：<https://orionsheep.github.io/safty-material-sim/>

页面上能做的事：

- 按类目、工厂、物料编码筛选，对照现行安全库存和建议值
- 用稳健、均衡、激进、极限四档重算，看建议是升、降还是先不动
- 看全局曲线：每天有多少物料在出库，实际在库低于现行值或建议值的有多少
- 单物料打开后看在库曲线、交货期和服务水平变了建议怎么变
- 偏差大的物料可以采纳、改成人工值，或保留现行值，并记下理由

建议值不是把现行数乘一个系数。按销售订单、BOM 到货的那部分需求先拿掉，剩下的需求按交货期累计，取服务水平分位数（默认 P90）。f-1 里的安全库存是申报触发点：可用加在途低于它就申报，补到最高库存。建议最高库存等于建议安全库存加上一次申报量。

判断能不能降库存，以近两个月实际自由在库为准。现场并不严格按现行值补货，实际在库往往比「按现行值模拟」高很多。

GitHub Pages 上是已经算好的结果，列表和全局曲线能直接看。重新试算、单物料曲线、人工确认和 AI 问答要在本机开服务：

```bash
python3 server.py
```

浏览器打开 <http://127.0.0.1:8770/>。依赖只有 Python 3 和 numpy。AI 助手需要环境变量 `ANTHROPIC_API_KEY` 或 `ANTHROPIC_AUTH_TOKEN`，不配也能用试算。
