安全库存曲线验证 · 看计划补货（降库存版）

①新规则：看计划补货

每天算「库存 + 在途 − 未来一个交货期内计划要发的量」，低于安全库存就下单。安全库存只是计划之外的缓冲，所以可以比现行值低很多。

②过拟合：拿 6 个月真实流水回放

真实的每日出库、每次到货的真实交货期，原样走一遍。找出满足率达标、下单次数不多于现场实际到货次数、平均在库最低的方案里安全库存最小的那个。

③防过拟合检查

只用前 3 个月拟合，再放到没见过的后 3 个月回放，看满足率掉多少；再每周用截至当天的数据重算一次，画出安全库存曲线。

说明与局限

  • 新安全库存的含义变了。现行做法是「在库 ≤ 安全库存就补」，安全库存要扛住整个交货期的用量；新规则是「在库 + 在途 − 交货期内计划用量 ≤ 安全库存就补」，安全库存只扛计划之外的波动。如果 f-1 仍按「在库 ≤ 安全库存」触发，等效触发线 = 新安全库存 + 交货期计划用量（每个物料的 KPI 里写了）。
  • 这是过拟合。回放时假设提前知道未来一个交货期内的真实出库（相当于生产计划/BOM 需求准确），交货期也用的是真实那次到货的交货期。计划不准时满足率会下降，看「后 3 个月检验满足率」那一列。
  • 数据：SAP 每日出入库 + 每日库存（），2026-05-01 ~ 10-31，库存与出入库逐日递推核对误差为 0。现场真实缺货在 SAP 里看不到（没货就不过账），实际一侧只能看日终库存为 0 的天数。
  • 样本只有 4 个物料、6 个月，只能说明方法可行，不能直接推到全部物料。
